# Home5a — запуск проекта

Проект состоит из фронтенда (React/Vite) и бэкенда. Для запуска нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

## Настройка

В корне проекта создайте или отредактируйте файл `.env`:

```env
# Абсолютный путь к папке с фотографиями на вашем компьютере
PHOTOS_ROOT=E:/Photos

# Перезапуск контейнеров после перезагрузки Docker
RESTART_POLICY=unless-stopped

# Адрес бэкенда, который будет доступен браузеру
VITE_API_URL=http://localhost:8000
```

Что означают настройки:

- `PHOTOS_ROOT` — папка с фотографиями на хост-компьютере. Она подключается к контейнеру бэкенда как `/app/photos`. Укажите существующий абсолютный путь; в Windows удобнее использовать `/`, например `E:/Photos`.
- `RESTART_POLICY` — правило перезапуска контейнеров. `unless-stopped` подходит для постоянного запуска; `no` удобно для разработки.
- `VITE_API_URL` — адрес API, который использует фронтенд. При запуске на том же компьютере оставьте `http://localhost:8000`. Чтобы открыть интерфейс с другого устройства в локальной сети, укажите IP компьютера, например `http://192.168.1.10:8000`.

## Запуск

```bash
docker compose up --build -d
```

После запуска откройте:

- фронтенд: http://localhost:3000
- API: http://localhost:8000

Чтобы остановить и удалить контейнеры, выполните `docker compose down`.

## После изменения `.env`

Перезапустите контейнеры, чтобы Docker применил новые переменные:

```bash
docker compose down
docker compose up --build -d
```
